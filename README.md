# driven.heg.wtf

Driven 드라이브 코스 추천 앱의 랜딩 페이지입니다.

## 기술 스택

- HTML5
- CSS3
- GitHub Pages

## 배포

GitHub Pages를 통해 자동으로 배포됩니다.

## 도메인

- Production: https://driven.heg.wtf

## 파일 구조

```
driven.heg.wtf/
├── index.html          # 메인 랜딩 페이지
├── css/
│   └── style.css       # 스타일시트
├── assets/
│   └── images/         # 이미지 파일
├── CNAME               # 커스텀 도메인 설정
└── README.md           # 이 파일
```

## 뉴스레터

뉴스레터 이메일 수집은 Formspree를 사용합니다.
실제 사용시 `index.html`의 form action에서 `YOUR_FORM_ID`를 실제 Formspree 폼 ID로 변경하세요
